Trabalhos Recentes

1. Perfil Profissional (Hard & Soft Skills)

Objetivo: Desenvolver uma tela de apresentação de hard skills e soft skills, dominando o alinhamento de itens.

Comandos: O código cria uma tela de perfil usando React Native, estruturada dentro de um SafeAreaView e um ScrollView. A seção de habilidades é organizada com flexDirection: "row", posicionando dois cartões lado a lado. A estilização é feita com StyleSheet, focando em criar um layout visual organizado e moderno.

2. Ficha de Personagem (RPG)

Objetivo: Treinar o uso avançado de Flexbox criando um layout temático de RPG.

Comandos: Cria um card de personagem de RPG organizando atributos com flexDirection: "row". As seções ficam lado a lado (força, agilidade, inteligência) e habilidades especiais. Utiliza imagens arredondadas e estilização específica com StyleSheet para garantir a imersão temática de um jogo.

Ver Projeto no Expo

3. Interatividade com Botões

Objetivo: Entender a interatividade com o usuário e o ciclo de vida de eventos de toque no React Native.

Comandos: O código utiliza o componente TouchableOpacity para criar botões interativos. É definida uma função no evento onPress, que é executada quando o botão é clicado para alterar o estado da tela ou exibir mensagens. Uma excelente base para entender como a interface responde às ações do usuário.

Ver Projeto no Expo

4. Catálogo de Filmes (Renderização Condicional)

Objetivo: Criar um sistema de paginação simulado usando controle de estados dinâmicos (useState).

Comandos: Implementa um app que apresenta botões representando filmes em cartaz. O evento onPress altera o estado da aplicação para renderizar uma nova "tela" condicionalmente (sem usar bibliotecas de navegação externas). Possui botão de voltar e manipulação de componentes de imagem dinâmicos.

Ver Projeto no Expo

5. Consumo de API (Previsão do Tempo / CEP) - Novo!

Objetivo: Integrar o aplicativo React Native com uma API externa usando requisições assíncronas.

Comandos: Este exemplo demonstra o uso da função fetch() combinada com async/await para buscar dados de um servidor na internet (como uma API de CEP ou clima). Os dados retornados em formato JSON são salvos em um estado (useState) e renderizados na tela. O layout foi construído com ActivityIndicator para mostrar o carregamento enquanto a resposta da API não chega.
