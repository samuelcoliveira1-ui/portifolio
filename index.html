App Copa do Mundo

React Native FlatList Modais

Objetivo: Desenvolver um aplicativo temático para exibir seleções de futebol e suas respectivas escalações detalhadas.

Resumo: Utiliza `FlatList` para renderizar uma lista de países, intercalando as cores de fundo dos cards usando lógica matemática. Cada card de seleção é interativo e atualiza o estado para abrir um `Modal` sobreposto, que exibe os 11 titulares mapeando os dados do array original.

Catálogo com Filtro de Busca

React Native Filtros Dinâmicos

Objetivo: Criar um catálogo interativo de jogos (Série Persona) com sistema de busca em tempo real e exibição de detalhes via Modal.

Resumo: O estado da lista de jogos é gerenciado com `useState`. O `TextInput` captura a digitação do usuário, filtrando os dados renderizados pela `FlatList` com a função `.filter()`. Ao tocar num jogo, um `Modal` exibe as informações detalhadas de preço, ID, categoria e status do estoque.
